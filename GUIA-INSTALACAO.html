Como este manual funciona

A instalação inteira é feita com a ajuda do Claude Code (o assistente de programação no seu computador). Você não precisa saber programar: o Claude executa os comandos por você e só pede os dados que só você tem (chaves e senhas).

Marque o checkbox de cada etapa conforme for concluindo. Seu progresso fica salvo neste navegador, então você pode fechar e voltar depois.

1 Baixar o código

Você recebeu o acesso a um repositório privado no GitHub. Clone-o no seu computador. Se não souber como, peça ao Claude Code (próxima etapa) que ele faz. Manualmente seria:

git clone https://github.com/Outlier Agency/criativos-entrega.git criativos
cd criativos
Confidencial: este código é proprietário e sob NDA. Se você for versioná-lo, use sempre um repositório privado seu. Nunca torne público.
✓
Baixei o código e ele está numa pasta no meu computador.

2 Deixar o Claude Code conduzir

Abra o Claude Code dentro da pasta do projeto e cole o prompt abaixo. Ele vai ler o roteiro de instalação que já vem no projeto (SETUP-CLAUDE.md) e te guiar passo a passo, pedindo os dados quando precisar.

Leia o arquivo SETUP-CLAUDE.md deste projeto e conduza a minha
instalação do Criativos na nuvem do zero, seguindo os passos na ordem.
Eu não sou técnico: execute os comandos por mim, me explique cada passo
em linguagem simples e me peça os valores (chaves, senhas, dados de conta)
quando você precisar. Vamos um passo de cada vez.
Dica: a partir daqui, é só responder o que o Claude perguntar. As próximas etapas deste manual servem para você acompanhar o que ele está fazendo e marcar o progresso.
✓
Abri o Claude Code na pasta do projeto e colei o prompt acima.

3 Instalar as dependências

O Claude vai rodar npm install (baixa as bibliotecas do sistema). Leva 1 a 3 minutos.

✓
As dependências foram instaladas sem erro.

4 Criar o banco no Supabase

No Supabase: New Project. Anote a senha do banco. Depois, em Project Settings → API, o Claude vai te pedir estes valores (copie e cole pra ele quando solicitado):

ValorOnde achar
Project URLSettings → API → Project URL
anon publicSettings → API → Project API keys → anon
service_roleSettings → API → service_role (clicar em "Reveal")
Project Refestá na URL: app.supabase.com/project/SEU-REF
Senha do bancoSettings → Database (ou "Reset database password")
A chave service_role é secreta — dá acesso total ao banco. Passe só para o Claude colar no .env.local. Nunca publique.
✓
Criei o projeto no Supabase e anotei a senha do banco.
✓
Passei ao Claude os valores da API (URL, anon, service_role, Ref).

5 Configurar variáveis e chave de criptografia

O Claude vai criar o arquivo .env.local com os valores que você passou e gerar uma chave de criptografia (com openssl rand -hex 32) — ela protege as chaves de IA que você cadastrar depois.

Importante: essa chave de criptografia é definida uma única vez. Se mudar depois, as chaves de IA salvas param de funcionar. O Claude vai te avisar disso.
✓
O .env.local foi preenchido e a chave de criptografia foi gerada.

6 Subir o banco de dados

O Claude roda, na ordem: supabase login → supabase link → supabase db push. Isso cria todas as tabelas, as regras de segurança, os buckets de armazenamento e a tabela de aceite de licença. É automático.

✓
O supabase db push rodou sem erro (banco criado).

7 Publicar na nuvem (Vercel)

O Claude vai te orientar a importar o repositório na Vercel e a colar as variáveis de ambiente lá (as mesmas do .env.local). Ao concluir o deploy, o sistema ganha uma URL pública. Você pode apontar seu próprio domínio depois.

✓
Importei o projeto na Vercel e adicionei as variáveis de ambiente.
✓
O deploy concluiu e o sistema abre na URL da Vercel.

8 Cadastrar as chaves de IA

Com o sistema no ar, crie sua conta, faça login e aceite o termo de licença que aparece no primeiro acesso. Depois vá em /configuracoes e cadastre pelo menos uma chave de IA. Sem isso, a geração de imagens não funciona.
